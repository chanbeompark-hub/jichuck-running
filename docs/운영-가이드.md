## ④ 인증 기록하기

구글 시트 한 장이면 됩니다. 자동 집계 장치는 만들지 마세요. 인원이 20~30명일 때는
일요일 저녁에 10분 손으로 적는 편이 더 빠르고 덜 고장납니다.

**시트 만들기** — 새 스프레드시트에 `기록` 시트를 만들고 세 열만 씁니다.

| A | B | C |
|---|---|---|
| 이름 | 날짜 | 거리(km) |
| 김OO | 2026-09-06 | 3.2 |
| 김OO | 2026-09-08 | 5.0 |

일요일에 오픈채팅방 사진을 보면서 한 줄씩 추가하면 끝입니다.

**집계 시트** — 시트를 하나 더 만들고 `집계` 로 이름을 바꾼 뒤, A1·B1·C1에 각각 넣습니다.

```
=UNIQUE(FILTER(기록!A2:A, 기록!A2:A<>""))
```

```
=ARRAYFORMULA(IF(A1:A="", "", COUNTIFS(기록!A:A, A1:A, 기록!C:C, ">=1")))
```

```
=ARRAYFORMULA(IF(A1:A="", "", SUMIFS(기록!C:C, 기록!A:A, A1:A, 기록!C:C, ">=1")))
```

이름 목록, 인증 횟수, 누적 거리가 자동으로 채워집니다. 수식은 이 세 개가 전부입니다.

### 혜택 달성 확인

**E1** 에 아래를 넣으면 누가 혜택 기준에 도달했는지 한눈에 보입니다.

```
=ARRAYFORMULA(IF(A1:A="", "", IF(B1:B>=30, "🎁 굿즈", IF(B1:B>=20, "🎟 우선권", IF(B1:B>=10, "🥤 음료 지급", "")))))
```

10회를 채운 회원이 보이면 오픈채팅방에서 축하해 주시고 음료를 챙겨드리면 됩니다.

**월 무료는 따로 봅니다.** 월말에 그 달 인증 건수만 세어, 10회 이상인 회원은 다음 달 구독료를 받지 않습니다.
돈을 돌려주는 정산이 없어 운영이 간단하고, 다음 달에도 계속 나오게 만드는 효과가 있습니다.
시트에 날짜가 있으니 아래 수식으로 이름별 이번 달 횟수를 셀 수 있습니다.

```
=COUNTIFS(기록!A:A, A1, 기록!B:B, ">="&EOMONTH(TODAY(),-1)+1, 기록!B:B, "<="&EOMONTH(TODAY(),0))
```

인원이 적을 때는 눈으로 세셔도 충분합니다.

사이트에는 누적 현황판을 두지 않습니다. 매주 수치를 옮겨 적는 일이 결국 부담이 되고,
인증은 오픈채팅방에 사진이 쌓이는 것만으로도 충분히 보입니다.
회원이 30명쯤 모여 "내가 몇 회 했더라"가 궁금해질 때, 그때 기록판을 만들어도 늦지 않습니다.

> 시트도 부담스러우시면 첫 달은 오픈채팅방 사진만 보고 수첩에 적으셔도 됩니다.
