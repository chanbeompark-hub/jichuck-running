# 1986 RUNNING CLUB 운영 가이드

사이트는 배포됐고 오픈채팅방도 개설됐습니다. 남은 것은 구글폼 2개와 시트 집계입니다.
이 문서는 만드는 순서와, 그대로 복사해 쓸 수 있는 내용을 담았습니다.

순서는 **① 오픈채팅방 ✅ → ② 가입 폼 → ③ 인증 폼 → ④ 시트 집계 → ⑤ 사이트에 주소 넣기** 입니다.

집결 지점은 **창릉천 통일교 앞**(지축역에서 창릉천 방향 도보 약 7분)으로 확정했습니다.

## ③ 러닝 인증 폼

제목 `1986 RUNNING CLUB 러닝 인증`, 설명 `1km 이상 달렸다면 인증 1회입니다.`

| # | 질문 | 유형 | 비고 |
|---|---|---|---|
| 1 | 이름 | 단답형 | 필수. **매번 같게 적어야 집계됩니다** |
| 2 | 러닝 날짜 | 날짜 | 필수 |
| 3 | 거리 (km) | 단답형 | 필수. 숫자만 (예: 3.2). 응답 확인 → 숫자 → 다음보다 큼 → `0.99` |
| 4 | 인증 사진 | 파일 업로드 | 필수. 이미지, 1개, 10MB |
| 5 | 한마디 | 단답형 | 선택 |

> 3번의 응답 확인을 걸어두면 1km 미만이 애초에 제출되지 않아 집계가 깔끔합니다.
> 파일 업로드는 응답자가 구글 로그인을 해야 합니다. 번거로워하시면 이 문항을 빼고
> 오픈채팅방에 사진을 올리게 하셔도 됩니다.

## ④ 구글 시트 자동 집계

인증 폼 → 응답 탭 → 시트 아이콘으로 스프레드시트를 만듭니다.
응답 시트 이름이 `설문지 응답 시트1` 이라고 가정합니다 (다르면 수식의 시트 이름만 바꾸세요).

새 시트를 하나 추가하고 이름을 `집계` 로 바꾼 뒤, 아래를 그대로 넣습니다.

**A1** — 이름 목록 (자동으로 늘어납니다)

```
=UNIQUE(FILTER('설문지 응답 시트1'!B2:B, '설문지 응답 시트1'!B2:B<>""))
```

**B1** — 인증 횟수 (1km 이상만)

```
=ARRAYFORMULA(IF(A1:A="", "", COUNTIFS('설문지 응답 시트1'!B:B, A1:A, '설문지 응답 시트1'!D:D, ">=1")))
```

**C1** — 누적 거리

```
=ARRAYFORMULA(IF(A1:A="", "", SUMIFS('설문지 응답 시트1'!D:D, '설문지 응답 시트1'!B:B, A1:A, '설문지 응답 시트1'!D:D, ">=1")))
```

**E1** — 혜택 달성 여부

```
=ARRAYFORMULA(IF(A1:A="", "", IF(B1:B>=30, "🎁 굿즈", IF(B1:B>=20, "🎟 우선권", IF(B1:B>=10, "🥤 음료 지급", "")))))
```

### 사이트에 붙여넣을 코드를 시트가 만들어 줍니다

**G1** 에 아래를 넣으면, 사이트 파일에 그대로 복사할 수 있는 형태로 나옵니다.

```
=TEXTJOIN(CHAR(10), TRUE, ARRAYFORMULA(IF(A1:A="", "", "    { name: """ & A1:A & """, count: " & B1:B & ", distance: " & TEXT(C1:C, "0.0") & " },")))
```

G1 셀을 복사해서 [`public/data/board.js`](../public/data/board.js) 의 `members: [ ... ]` 안쪽을 통째로 바꾸고,
`updated` 날짜를 오늘 날짜로 고친 뒤 저장하면 됩니다.

이름을 그대로 노출하기 싫으시면 A열 대신 `김OO` 형태로 표시할 열을 하나 더 만들어 그 열을 쓰세요.

## ⑤ 사이트에 주소 넣기

①②③에서 만든 주소를 [`public/index.html`](../public/index.html) 맨 위 `window.SITE` 에 넣습니다.
여기 한 곳만 고치면 사이트의 모든 버튼에 반영됩니다.

```js
window.SITE = {
  kakaoOpenChat: "https://open.kakao.com/o/pxirsJLi",  // ① 완료
  joinForm:      "https://forms.gle/...",          // ② 가입 신청 폼
  missionForm:   "https://forms.gle/...",          // ③ 러닝 인증 폼
  instagram:     "",
  naverMap:      "",                                // 통일교 집결 지점 (네이버 지도 공유 링크)
  phone:         ""                                 // 헬스장 전화번호
};
```

고친 뒤 배포:

```bash
npx wrangler deploy
```
